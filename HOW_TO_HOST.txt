HOST THE PRIVACY POLICY ON GITHUB PAGES (free, https, public)
1. Open index.html in a text editor and replace the two placeholders everywhere they appear:
     REPLACE_WITH_DEVELOPER_NAME  -> your name / Play developer name
     REPLACE_WITH_YOUR_EMAIL      -> your real contact email
2. github.com -> New repository -> name: cube-rush-privacy -> Public -> Create.
3. "Add file" -> "Upload files" -> drag index.html (and .nojekyll) -> Commit changes.
4. Settings -> Pages -> Source: "Deploy from a branch" -> Branch: main, folder: / (root) -> Save.
5. After ~1 minute your page is live at:
     https://YOUR-GITHUB-USERNAME.github.io/cube-rush-privacy/
   (GitHub provides a valid SSL certificate automatically.)
6. Test it: open the URL in a private/incognito window and on mobile data. It must open without login.
7. Paste that URL into Play Console -> Privacy policy URL, and send it to me so I can put it inside the app.
Alternatives (also free, https): Netlify Drop (app.netlify.com/drop, drag the folder), Cloudflare Pages.
